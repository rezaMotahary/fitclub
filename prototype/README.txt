پروتوتایپ مدیریت باشگاه فیت‌استیل
نسخه: Cyan Night (دیزاین ۲)
نوع فایل: نمونه اولیه UI برای تأیید کارفرما

----------------------------------------
چطور باز کنم؟
----------------------------------------
1) فایل ZIP را از حالت فشرده خارج کنید.
2) فایل index.html را با مرورگر (Chrome / Edge / Firefox) باز کنید.
3) از منوی بالا بین صفحات جابه‌جا شوید.

صفحات موجود:
- index.html        صفحه اصلی / معرفی باشگاه
- member.html       پنل اعضا
- secretary.html    پنل منشی
- admin.html        پنل مدیریت

----------------------------------------
نکات مهم
----------------------------------------
- این نسخه فقط پروتوتایپ ظاهری است و هنوز بک‌اند واقعی ندارد.
- داده‌های داخل صفحات نمونه و فرضی هستند.
- طراحی برای دسکتاپ، تبلت و موبایل آماده شده است.
- لطفاً بازخورد خود را درباره ظاهر، ترتیب بخش‌ها و کامل بودن اطلاعات اعلام کنید.
