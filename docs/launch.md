# مسیر تا لانچ — فیت‌کلاب

آخرین به‌روزرسانی: 2026-11-01  
سؤال مالک: «چه چیزهایی تا بالا آوردن روی سرور مانده؟» (۱۴۰۴/۰۸/۱۰)

این صفحه به زبان ساده می‌گوید **چه کارهایی مانده** تا نسخهٔ اول روی سرور باشگاه بالا بیاید. جزئیات فنی استقرار وقتی نوبتش شد نوشته می‌شود؛ تا آن موقع حدس زده نمی‌شود (هاست/دامنه هنوز از مالک گرفته نشده).

---

## الان کجاییم؟

هستهٔ کار باشگاه در مرورگر کار می‌کند و با QA جلو آمده:

- ورود سه نقش  
- اعضا، پلن، اشتراک، حضور  
- پرداخت دستی پذیرش  
- داشبورد عضو  
- **پنل مدیر v2** — تأیید QA / مالک  
- **خانهٔ پذیرش منشی** — تأیید QA  

هسته، ظاهر، متن، لینک مخفی، لوگو، PWA، بررسی امنیت، و ابزار استقرار بدون پاک شدن داده (`0.16.0`) آماده‌اند. سایت آموزشی روی `https://fitclubapp.shop` باز است. پیامک واقعی و اطلاعات رسمی باشگاه برای نسخهٔ باشگاه واقعی می‌مانند؛ این سرور با کد ثابت و صفحهٔ راهنما بالا آمده است.

### امنیت قبل از لانچ

✅ بررسی کامل امنیت انجام شد (۱۴۰۴/۰۸/۱۰، نسخه `0.15.0`) — ۱۲ مشکل پیدا و رفع شد. چک‌لیست امنیتی روز سرور در `docs/security.md` است و موقع استقرار باید کامل اجرا شود.

تصمیم مالک ۱۴۰۴/۰۸/۱۰: این سرور **تستی و آموزشی** است → با `DEMO_MODE=true` بالا می‌آید: ورود عضو با کد ثابت `123456` بدون پیامک، و `/how-to-open` با لینک و رمز نمونه برای همه باز. بقیهٔ قفل‌های امنیتی می‌مانند. جزئیات: `docs/security.md` → «حالت دمو».

قانون دادهٔ همان روز: روی سرور داده پاک نشود، seed فیک لوکال نرود، آپدیت فقط افزایشی، فقط سه حساب تست. → `docs/production-data.md`

### پ) بالا آوردن روی سرور — سایت روی دامنه باز است

اسکریپت ایمنی داده و مسیر آپدیت آماده است (`0.16.0`، `docs/server-update.md`). دامنهٔ هدف: **fitclubapp.shop**. برنامه روی سرور نصب شد و داده پاک نشد. مالک ترمینال نمی‌زند.

| کار | وضعیت |
|-----|--------|
| bootstrap سه‌حساب بدون پاک کردن دیتابیس | ✅ انجام شد — یک مدیر، یک منشی، یک عضو تست |
| قفل seed لوکال روی سرور، حتی با `DEMO_MODE` | ✅ seed اجرا نشد |
| پشتیبان قبل از آپدیت + دامپ روزانه | ✅ پوشهٔ `/var/backups/fitclub` و زمان شبانه |
| آپدیت: بکاپ → pull → `migrate deploy` → build → روشن کردن دوباره | ✅ سرویس‌ها: `fitclub-api` و `fitclub-web` |
| تنظیمات محرمانه روی سرور (نه داخل GitHub) | ✅ env روی سرور است؛ در گیت نیست |
| https و باز شدن دامنه | ✅ `https://fitclubapp.shop` — خطای ۵۰۲ با گواهی سبز حل شد (۱۴۰۴/۰۸/۱۱) |

| بستن خودکار خروج آخر سانس روی سرور | همان برنامه است؛ API روشن است |
| یک دور تست QA روی آدرس واقعی | مانده تا `https://fitclubapp.shop` باز شود |
