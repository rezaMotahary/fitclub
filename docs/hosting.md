## سرور — همین را بخر

نوع درست: **سرور مجازی لینوکس (VPS)** با دسترسی کامل.  
نه هاست معمولی وردپرس، نه سرور ویندوز، نه سرور اختصاصی گران.

| مورد | انتخاب |
|------|--------|
| سیستم‌عامل | **Ubuntu 24.04** (لینوکس اوبونتو ۲۴). اگر ۲۴ نبود، **Ubuntu 22.04** |
| قدرت | **۲ هسته** · **۴ گیگ حافظه (RAM)** · حداقل **۵۰ گیگ دیسک SSD** |
| شبکه | یک آدرس اینترنتی ثابت (**IPv4**) |
| دسترسی | ورود کامل به سرور (root / SSH). پنل شرکت برای خاموش/روشن کافی است |
| شرکت | هر شرکت معتبر ایرانی یا خارجی با همین مشخصات. برای آموزش داخل ایران، سرور داخل ایران معمولاً باز شدن صفحه را برای هنرجو راحت‌تر می‌کند |
| مدت | ماهانه؛ پلن کوچک همین مشخصات کافی است. بزرگ‌تر لازم نیست |

اگر فروشنده چند گزینه سیستم‌عامل گذاشت: **Ubuntu** را بزن. AlmaLinux، CentOS، Debian، Windows را نگیر.

اگر پلن دقیقاً ۴ گیگ نبود: **کمتر از ۲ گیگ نگیر.** ۸ گیگ هم اگر ارزان است اشکال ندارد؛ لازم نیست.
