## نام پروژه

**فیت‌کلاب (FitClub)**

این نام رسمی پروژه نرم‌افزاری است و باید در مستندات، ریپو، و ارتباط با مالک همین باشد.

ریپو: `rezaMotahary/fitclub`

> توجه: در پروتوتایپ UI برند باشگاه به‌صورت **فیت‌استیل / FITSTEEL** آمده بود. آن برند نمایشی پروتوتایپ است؛ **نام پروژه = فیت‌کلاب**. اگر متن‌های UI هم باید همه‌جا FitClub شود (به‌جای FitSteel)، مالک تأیید می‌کند.
