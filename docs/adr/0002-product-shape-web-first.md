# ADR-0002: شکل محصول — وبسایت ریسپانسیو اول

- Status: Accepted
- Date: 2026-10-08

## Context

پروتوتایپ چهار سطح دارد: سایت عمومی، پنل عضو، پنل منشی، پنل ادمین. نیاز کسب‌وکار فعلی یک باشگاه است؛ ورود/خروج دستی توسط منشی انجام می‌شود. اپ موبایل native در حال حاضر در scope نیست. احتمال PWA در آینده مطرح شده است.

## Decision

- محصول نسخهٔ اول یک **وبسایت ریسپانسیو واحد** است (سایت + پنل‌ها در یک سیستم).
- اپ native (iOS/Android) ساخته نمی‌شود.
- آماده‌سازی سبک برای PWA مجاز است. پیاده‌سازی کامل PWA طبق ADR-0004 و `docs/pwa.md` در مرحلهٔ مناسب انجام می‌شود (هدف محصول تأییدشدهٔ مالک؛ نه «هرگز»).
- محدودهٔ دامنه: **یک باشگاه** (فیت‌استیل)، نه پلتفرم چندشعبه‌ای SaaS در MVP.

## Consequences

- یک codebase وب برای همه نقش‌ها کافی است؛ هزینه توسعه و استقرار کمتر است.
- منشی و مدیر روی تبلت/موبایل مرورگر هم باید بتوانند کار کنند (UI ریسپانسیو الزامی است).
- اگر بعداً PWA لازم شد، می‌توان بدون عوض کردن استک اصلی اضافه کرد.
- اگر بعداً چند شعبه لازم شد، باید مدل داده و دسترسی با ADR جدا بازنگری شود.
