# ADR-0004: هدف محصولی PWA برای فیت‌کلاب

- Status: Accepted
- Date: 2026-10-14

## Context

در ADR-0002 شکل محصول «وب ریسپانسیو اول» بدون اپ native ثابت شد و PWA فقط به‌عنوان امکان آینده ذکر شد. مالک در ۱۴۰۴/۰۷/۲۲ تأیید کرد که **می‌خواهد پروژه PWA داشته باشد** و عامل باید وقتی مرحله مناسب رسید یادآوری کند، پیاده کند، و تست کند.

## Decision

- PWA یک **هدف محصولی تأییدشده** است (نه صرفاً ایدهٔ باز).
- زمان پیاده‌سازی: وقتی وب‌اپ به مرحلهٔ قابل‌استفادهٔ معنادار رسید؛ جزئیات زمان‌بندی در `docs/pwa.md`.
- اپ native همچنان خارج از محدوده است.
- ADR-0002 از نظر «وب اول / بدون native» پابرجاست؛ بخش «PWA الان انجام نمی‌شود» با این ADR برای **برنامه‌ریزی و الزام بعدی** تکمیل می‌شود.

## Consequences

- عامل نباید PWA را برای همیشه عقب بیندازد یا فراموش کند؛ باید در مراحل مناسب یادآوری و پیاده‌سازی کند.
- قبل از هستهٔ دامنه (اعضا / اشتراک / حضور) اولویت با منطق باشگاه و صفحات قابل‌دیدن است.
- بعد از پیاده‌سازی باید تست نصب‌پذیری انجام و در handoff ثبت شود.
