# تم روشن و تاریک — فیت‌کلاب

آخرین به‌روزرسانی: 2026-10-15  
تأیید قانون مالک: ۱۴۰۴/۰۷/۲۲ · تأیید پیاده‌سازی مالک: ۱۴۰۴/۰۷/۲۳

## قانون محصول

سایت و همهٔ پنل‌ها باید **هم تم تاریک (شب)** و **هم تم روشن (روز)** داشته باشند.

- کاربر بتواند بین روز / شب جابه‌جا شود (یک دکمهٔ واضح، همه‌جا در دسترس).
- انتخاب تم باید یادش بماند (مثلاً دفعهٔ بعد همان تم باز شود).
- ظاهر باید **تمیز و یکدست** باشد: وقتی روشن است هیچ گوشه‌ای تیرهٔ جا‌مانده نباشد؛ وقتی تاریک است هیچ بخش روشنی جا نماند.
- رنگ‌ها از متغیرهای مشترک بیایند؛ رنگ ثابت پراکنده برای پس‌زمینه/متن/کادر ممنوع مگر استثنا با دلیل.

وضعیت پیاده‌سازی: **✅ آماده (v0.5.0)** — روز/شب با `data-theme`، یادآوری در `localStorage`، دکمه در هدر سایت و همهٔ صفحات ورود/پنل.

## محدوده

شامل:

- سایت عمومی
- صفحات ورود
- پنل عضو / منشی / مدیر
- هر صفحهٔ جدید بعدی

## پیاده‌سازی فنی (خلاصه برای عامل)

| مورد | محل |
|------|------|
| متغیرهای رنگ تاریک/روشن | `web/src/app/globals.css` (`:root` / `[data-theme="dark"]` و `[data-theme="light"]`) |
| منطق + کلید ذخیره | `web/src/lib/theme.ts` (`fitclub-theme`) |
| جلوگیری از چشمک اشتباه | اسکریپت bootstrap در `web/src/app/layout.tsx` |
| Provider و دکمه | `ThemeProvider` · `ThemeToggle` |
| هیرو | تاریک: `/images/hero.jpg` · روشن: `/images/hero-light.jpg` (متغیر `--hero-image`) |

اولویت انتخاب: ذخیرهٔ کاربر → ترجیح سیستم → پیش‌فرض تاریک (برند Cyan Night).

صفحات جدید باید فقط از متغیرهای CSS استفاده کنند و `ThemeToggle` را در هدر/ناوبری داشته باشند.
