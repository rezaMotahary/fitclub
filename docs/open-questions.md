# سؤال‌های باز — فیت‌کلاب

آخرین به‌روزرسانی: 2026-10-21

قانون‌های لازم برای ساخت هسته بسته شده‌اند. آنچه اینجاست مانع کدنویسی نیست؛ داده است و بعداً جایگزین نمونه می‌شود. سؤال‌های محصولی جدید هم اینجا می‌آیند تا حدس زده نشوند.

---

## مانده — داده، نه قانون

| مورد | وضعیت |
|------|--------|
| قیمت واقعی پلن‌ها | نمونهٔ پروتوتایپ تا مدیر عوض کند |
| ساعت واقعی سانس آقایان و بانوان | نمونهٔ پروتوتایپ تا مدیر عوض کند |
| تلفن، آدرس، و شبکه‌های تماس | نمونه است؛ مالک بعداً متن واقعی را می‌دهد |

اگر مالک عدد یا آدرس واقعی گفت، همان را در تنظیمات و در این جدول بنویس و از حالت نمونه دربیاور.

---

## مانده — محصول

_(فعلاً سؤال محصولی بازی نیست.)_

### بسته‌شده — آفر / قیمت (جواب مالک ۱۴۰۴/۰۷/۲۹)

| سؤال | جواب |
|------|------|
| منظور از «آفر ویژه» در این نسخه چیست؟ | همان **تغییر قیمت پلن‌ها** توسط مدیر (مثلاً پلن ۳ روز → ۳٬۰۰۰٬۰۰۰ تومان). لفظی گفته شده بود؛ کمپین جدا نیست. |
| کد تخفیف زمان‌دار (مثلاً یک ماه ۲۰٪) | **برای این نسخه نه**؛ ممکن است در آینده خواسته شود — تا آن موقع نساز. |
| تخفیف تمدید زودتر (درصد مدیر) | از قبل در قوانین هست؛ جدا از «آفر» لفظی بالا می‌ماند. |

## بسته‌شده در دور ۶

| سؤال | جواب |
|------|------|
| زمان پیامک | انقضا: ۱۴ روز مانده و صبح روز ۳۰. بدهی: ۹ صبح روز ۱۵ اگر تسویه نشده |
| آرشیو | منشی و مدیر هر دو |
| «جلسه در ماه» | فقط توضیح سایت؛ شمارنده در پنل عضو نیست |
| کد عضویت | `FS-` و شماره |
| تماس پروتوتایپ | نمونه |
| مربی | پنل در نسخهٔ اول نیست |
| یادداشت شیفت | در نسخهٔ اول نیست |
| تمدید دوباره | تا شروع دورهٔ بعدی ممنوع؛ دورهٔ سوم در صف نیست |
