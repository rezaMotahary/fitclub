# واژه‌نامه — فیت‌کلاب

آخرین به‌روزرسانی: 2026-10-08

زبان ساده برای دامنهٔ باشگاه. تعریف دقیق حضور و اشتراک در [business-rules.md](./business-rules.md) است.

| واژه | معنی |
|------|------|
| عضو | کسی که اشتراک دارد و با موبایل وارد پنل خودش می‌شود. فقط دادهٔ خودش را می‌بیند. |
| منشی | پرسنل پذیرش. ورود و خروج را دستی ثبت می‌کند. |
| مدیر | پرسنل مدیریت باشگاه. دسترسی کامل‌تر از منشی؛ جزئیات در [user-roles-permissions.md](./user-roles-permissions.md). |
| مهمان سایت | بازدیدکنندهٔ سایت عمومی، بدون حساب. |
| سانس | بازهٔ ساعتی جدا برای آقایان یا بانوان. ورود فقط داخل سانس جنس خود عضو است. عدد ساعت تعرفهٔ ثابت نیست و باید در سیستم تنظیم شود. |
| پلن | نوع اشتراک: ۲، ۳، یا ۴ روز در هفته، یا «هر روز» با سقف ۷. قیمت برای ۳۰ روز است و عددش باید در سیستم باشد، نه ثابت پروتوتایپ. |
| دورهٔ اشتراک | ۳۰ روز پشت سر هم. روز شروع روز ۱ است و روز ۳۰ آخرین روز مجاز است. |
| روز آخر | روز ۳۰. تا پایان سانس همان روز می‌شود وارد شد. |
| هفتهٔ حضور | شنبه تا جمعه. ابتدای شنبه سهم صفر می‌شود. |
| سقف هفتگی | حداکثر روزهای قابل‌شمارش در همان هفته، برابر عدد پلن. |
| روز شمرده‌شده | یک روز تقویمی که برایش خروج (دستی یا خودکار) ثبت شده. بار دوم همان روز روز تازه نیست. |
| ماندهٔ هفته | سقف پلن منهای روزهای شمرده‌شدهٔ این هفته. روز استفاده‌نشده به هفتهٔ بعد نمی‌رود. |
| حضور | یک نوبت: ساعت ورود، ساعت خروج، مدت، و کسی که ثبت کرده. |
| حضور باز | ورود ثبت شده و خروج هنوز نخورده. عضو «داخل سالن» است. ورود دوباره تا خروج مجاز نیست. |
| بستن خودکار | اگر خروج یادشان برود، در پایان سانس همان جنس، سیستم خروج را ثبت می‌کند و آن روز را می‌شمارد. |
| ورود ردشده | تلاشی که ثبت نشده. در لاگ امروز هست، سهم هفته را کم نمی‌کند. |
| بدهی | فقط ماندهٔ شهریه. کمتر از نصف برای شروع قبول نیست. با حداقل نصف، روز ۱ تا ۱۴ ورود باز است. از روز ۱۵ تا تسویه بسته است و روزهای دیرکرد می‌سوزد. |
| ابطال حضور | لغو اثر یک حضور تا پایان همان روز، توسط منشی یا مدیر. رکورد با علامت باطل می‌ماند. اگر تنها حضور آن روز باشد، سهم برمی‌گردد. |
| آرشیو | عضو غیرفعال با سوابق باقی‌مانده. می‌شود دوباره فعالش کرد. اشتراک در این مدت متوقف نمی‌شود. |
| یادآوری داخل برنامه | از ۱۴ روز مانده به پایان اشتراک نشان داده می‌شود. خودش تمدید نمی‌کند. |
| یادآوری پیامکی | رمز ورود همان لحظه. انقضا وقتی ۱۴ روز مانده و ساعت ۹ صبح روز آخر. بدهی ساعت ۹ صبح روز ۱۵ اگر شهریه کامل نباشد. |
| تمدید | خریدن دورهٔ بعد. اگر دوره باز است، دورهٔ جدید فردای پایان شروع می‌شود. تا دورهٔ بعدی شروع نشده، تمدید دوباره ممنوع است. |
| کد عضویت | شناسهٔ یکتا که سیستم می‌سازد: `FS-` و شماره، مثل `FS-1042`. |
| شیفت | نوبت کاری پرسنل. یادداشت شیفت در نسخهٔ اول نیست. |
| مربی | اسمش می‌تواند روی پروندهٔ عضو باشد. پنل ورود در نسخهٔ اول ندارد. |
| تخفیف تمدید زودتر | درصدی که فقط مدیر تعیین می‌کند. صفر یعنی بدون تخفیف. فقط وقتی تمدید قبل از پایان دوره ثبت شود. |
| منقضی | بعد از پایان سانس روز ۳۰. ورود بسته است. |
| ثبت‌کننده | منشی‌ای که ورود یا خروج را زده. |
