# داده‌های نمونه — قانون الزامی

آخرین به‌روزرسانی: 2026-10-21

---

## قانون

مالک پروژه نباید صفحهٔ خالی ببیند.

برای **هر فیچر و هر قابلیتی** که پیاده می‌شود:

1. داده‌های نمونهٔ اولیه حتماً وجود داشته باشد (seed / fixture)
2. بشود همان داده‌ها را در UI دید
3. بشود دادهٔ جدید هم توسط کاربر وارد کرد (خالیِ صرف ممنوع)

---

## حداقل‌ها (وقتی هسته آماده شد)

- چند عضو نمونه (با کد عضویت، پلن، سانس)
- پلن‌های اشتراک (۲ / ۳ / ۴ / هر روز با سقف ۷)
- یک عضو با پرداخت نصف که در روز ۱۰ است (ورود باز) و یکی که در روز ۱۶ است و هنوز تسویه نکرده (ورود بسته)
- یک حضور باطل‌شده در همان روز، و یک حضور که خروجش خودکار بسته شده
- یادآوری انقضا برای اشتراکی که ۱۴ روز یا کمتر مانده
- درصد تخفیف تمدید در تنظیمات مدیر (نمونه می‌تواند ۱۰ باشد)
- ساعت و قیمت پروتوتایپ فقط به‌عنوان نمونه، نه تعرفهٔ رسمی
- کد عضویت نمونه با پیشوند `FS-`

جزئیات seed در بک‌اند (`api/prisma/seed.ts`) نگه‌داری می‌شود و با فیچرهای جدید گسترش می‌یابد.

### seed پایه فعلی (`npx prisma db seed`)

| نوع | نمونه |
|-----|--------|
| پلن‌ها | ۲ / ۳ / ۴ / هر روز با قیمت نمونهٔ پروتوتایپ (۸۹۰٬۰۰۰ … ۱٬۷۹۰٬۰۰۰ تومان) |
| مدیر | کاوه احمدی — `admin@fitclub.local` / `FitClubAdmin1!` (فقط لوکال) |
| منشی | مریم صالحی (شیفت صبح بانوان) — `secretary@fitclub.local` / `FitClubSecretary1!` |
| اعضا | `FS-1042` سارا کریمی (`09121234567`) برای تست OTP؛ چند عضو دیگر با کد `FS-…`؛ یکی حدود روز ۱۰ با بدهی نصف، یکی حدود روز ۱۶ با بدهی نصف |
| عضو آرشیو | `FS-1099` موبایل `09129990000` — ورود OTP به پنل باید رد شود؛ در جستجوی عادی مخفی است مگر «آرشیو هم نشان بده» |
| تخفیف تمدید زودتر | `ClubSettings.earlyRenewalDiscountPercent` پیش‌فرض ۱۰ (نمونه؛ مدیر عوض می‌کند) |
| OTP توسعه | `OTP_DEV_CODE=123456` (در `api/.env` و توضیح در `docs/.env.example`) — پیامک واقعی نیست |
| حضور نمونه | `FS-1045` سقف هفته پر (اگر حداقل ۲ روز از هفته گذشته باشد)؛ `FS-1046` رد بدهی در لاگ امروز؛ `FS-1043` حضور باطل‌شدهٔ امروز؛ `FS-1048` خروج خودکار آخر سانس؛ `FS-1042` حضور بسته‌شدهٔ هفته + امروز ۰۸:۱۵→۱۰:۰۱ با مدت سازگار (بدون حضور باز — KI-003) |
| داشبورد عضو | `FS-1042` سارا (~۱۲ روز مانده → اعلان نزدیک انقضا؛ سهم هفته؛ سوابق حضور؛ پرداخت نمونه) |
| داشبورد مدیر | پرداخت‌های seed در ماه جاری شمسی → درآمد پذیرش؛ اعضا با ≤۱۴ روز مانده در «نزدیک انقضا» |
| پرداخت / بدهی | `FS-1045` روز ~۱۰ نصف‌پرداخت (ورود باز)؛ `FS-1046` روز ~۱۶ نصف‌پرداخت (ورود بسته) — برای ثبت قسط/تسویه در `/secretary/payments` و `/admin/payments` |
| پرداخت تسویه‌شده | اعضای بدون بدهی: دو رکورد `Payment` (قسط اول نقد + تسویه کارت‌خوان) تا سوابق خالی نباشد |
| مشاهدهٔ عضو | سارا در `/member` فقط سوابق پرداخت خودش را می‌بیند (بدون ثبت از پنل) |

رمزها و کد OTP فقط برای محیط لوکال/نمونه هستند؛ در `api/prisma/sample-credentials.ts` نگه‌داری می‌شوند و اسرار واقعی commit نمی‌شوند.
