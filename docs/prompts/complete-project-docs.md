# پرامپت سشن تکمیل مستندات فیت‌کلاب

این فایل را کامل کپی کن و در یک **چت جدید** Cursor بفرست.

> مسیر پروژه و «برو داک بخوان» عمداً اینجاست نیست — آن‌ها قانون دائمی پروژه هستند  
> (`.cursor/rules/always-read-docs.mdc` · `docs/collaboration.md`).

---

## متن پرامپت (از اینجا کپی کن)

```text
هدف این چت: تکمیل خیلی کامل مستندات و منطق/کسب‌وکار فیت‌کلاب. هنوز فیچر سنگین نساز مگر برای ثبت مستند لازم باشد. تمرکز: پیدا کردن حفره، سؤال از من، نوشتن و به‌روز کردن docs.

قوانین دائمی پروژه (vibe coding، خواندن خودکار docs، تصمیم‌گیری ~۹۰٪، GitHub، تست، داده نمونه، RTL/شمسی، سه نقش، برند FitClub) را رعایت کن — لازم نیست دوباره تکرارشان کنم.

## خروجی این سشن
مستندات را طوری تکمیل کن که چت بعدی بدون حدس بتواند اپ را بسازد.

حداقل این‌ها را بساز یا تکمیل کن (ساختار را اگر بهتر شد منظم کن و docs/README را به‌روز کن):

A) docs/business-rules.md — قوانین کسب‌وکار کامل (عضویت، پلن، سقف هفته، تعریف هفته، ورود/خروج، بدهی، تمدید، سانس، پرداخت، اعلان، شیفت، استثناها و موارد لبه)
B) docs/user-roles-permissions.md — ماتریس دسترسی عضو / منشی / مدیر
C) docs/domain-glossary.md — واژه‌نامه ساده
D) docs/user-flows.md — جریان‌های اصلی قدم‌به‌قدم
E) docs/mvp-scope.md — هست / نیست نسخه اول
F) docs/open-questions.md — سؤال‌های باز
G) به‌روز کردن product-overview و handoff
H) ADR جدید فقط اگر لازم شد

## روش کار
1. حفره‌ها و ابهام‌ها را از docs + prototype استخراج و اولویت‌بندی کن (ورود و اشتراک اول).
2. سؤال‌ها را فارسی، کوتاه، در چند دور بپرس — نه یک دیوار طولانی.
3. چیزهایی که ممکن است به ذهنم نرسیده هم بپرس؛ حدس نزن. نمونه حوزه‌ها: شروع هفته، ورود بدون خروج، چند ورود در یک روز، تعریف بدهی، فروش/تمدید توسط منشی، پرداخت آنلاین عضو، محل ثبت‌نام، پیامک، خارج از سانس، اصلاح اشتباه منشی، آرشیو عضو، گزارش مالی، تک‌باشگاه بودن، فقط فارسی بودن.
4. بعد از هر دسته جواب: همان دور مستند کن، بعد دور بعد.
5. پایان سشن: خلاصهٔ تکمیل‌شده‌ها + سؤال‌های باز + handoff آمادهٔ کدنویسی.

الان شروع کن: حفره‌ها را فهرست کن و اولین دسته سؤال‌های بااولویت را بپرس.
```
