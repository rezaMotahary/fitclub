## KI-008 — جای پیام
الان `error` و `note` سراسری بالای کل `AdminDesk` است (`web/src/components/AdminDesk.tsx` حدود ۳۱۷–۳۱۸). جستجو می‌گوید «نتیجه جستجو به‌روز شد» بالای صفحه.

رفتار درست: هر پیام تأیید/خطا **کنار همان بخش**:
- جستجوی عضو → زیر/کنار فرم جستجو
- فیلتر ماه/بازه → کنار فرم درآمد
- ذخیره قیمت پلن → کنار همان کارت تعرفه
- تخفیف تمدید → کنار همان فرم
- آرشیو/فعال‌سازی → کنار همان عضو یا لیست اعضا

اگر چند پیام هم‌زمان ممکن است، فقط همان بخش مربوط را نشان بده. نوار سراسری بالای صفحه برای این کارها حذف شود (خطای boot/ارتباط کل صفحه می‌تواند بالای صفحه بماند).

## KI-009 — تقویم شمسی از/تا
«از تاریخ» و «تا تاریخ» فقط input متن است. با کلیک/فوکوس یک **تقویم شمسی** باز شود (ماه/سال شمسی، انتخاب روز). مقدار ذخیره‌شده همان فرمت فعلی قابل‌ارسال به API بماند (`parseJalaliDateInput` در `web/src/lib/admin-overview.ts`). رقم فارسی و انگلیسی اگر تایپ کمکی ماند باید کار کند. تم روشن/تاریک + RTL. کتابخانهٔ سنگین تقویم میلادی که شمسی غلط نشان دهد ممنوع؛ از منطق جلالی موجود پروژه استفاده کن (`jalali-date` / `iran-month` سمت API برای اعتبار روز).

## KI-010 — مبلغ روی نمودار
`web/src/components/RevenueChart.tsx`: مبلغ فقط در `title` هاور است. روی/بالای هر ستون مبلغ خوانا باشد (مثلاً «۱٫۲ میلیون» یا تومان گروه‌بندی‌شده؛ اگر جا کم است خلاصهٔ فارسی واضح). بدون موس هم ماه آبان و مبلغش معلوم باشد. تم روشن/تاریک.

## KI-011 — برچسب روزانه بریده نشود
`.admin-bar-label` الان ellipsis دارد. نمودار «درآمد روزانه در بازه» برچسب کامل و خوانا: عرض کافی، چرخش ملایم، یا «۱ آبان» بدون «…». ستون‌ها روی هم نروند.

## KI-012 — قیمت سایت از تعرفه
`web/src/app/page.tsx` آرایهٔ ثابت `plans` با مبلغ هاردکد دارد. صفحهٔ اصلی باید قیمت را از `GET /api/plans` (عمومی/بدون لاگین اگر الان گارد دارد، گارد را برای خواندن قیمت عمومی درست کن — فروش/PATCH همچنان فقط مدیر). بعد از «ذخیره قیمت» در `/admin`، رفرش `/` همان عدد جدید را نشان دهد. متن «جلسه در ماه» روی سایت بماند (قانون محصول). اشتراک‌های فروخته‌شدهٔ قبلی قیمت خودشان را نگه می‌دارند (قانون فعلی تعرفه).
