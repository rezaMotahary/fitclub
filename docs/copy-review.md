# بازبینی متن‌های فارسی UI — فیت‌کلاب

آخرین به‌روزرسانی: 2026-11-01  
تأیید قانون مالک: ۱۴۰۴/۰۷/۲۹ · **بسته ۱۴۰۴/۰۸/۱۰** — متن‌ها را خود مالک تأیید می‌کند؛ QA جمله‌ها را دوباره نخواند

---

## قانون

قبل از **تحویل نهایی / نسخهٔ جدی برای باشگاه**، یک دور بازبینی روی **همهٔ متن‌هایی که کاربر می‌بیند** الزامی است.

هدف: متن‌ها برای کسی که فارسی عامیانه و روزمره حرف می‌زند، ساده، روان و بدون گیج‌کنندگی باشند.

---

## چه چیزهایی بررسی می‌شوند

- عنوان‌ها، دکمه‌ها، راهنماها، پیام خطا، پیام موفقیت  
- متن سایت عمومی و هر سه پنل (عضو / منشی / مدیر)  
- اعلان‌ها و برچسب‌های وضعیت (بدهی، انقضا، رد ورود، …)  

از نظر:

1. **نگارش و املا**  
2. **جمله‌نویسی** (کوتاه، واضح، طبیعی)  
3. **زبان فارسی قابل‌فهم** — نه رسمیِ سنگین یا مبهم که کاربر را گول بزند یا گیج کند  

---

## زمان انجام

- **نه وسط هر فیچر کوچک** مگر متن همان فیچر آشکارا خراب باشد.  
- **حتماً یک بار کامل** وقتی هسته و پنل‌های اصلی تقریباً جمع شدند و **قبل از تحویل نهایی** (قبل از اینکه «تمام شد، بده دست باشگاه» گفته شود).  

این دور انجام شد. مالک ۱۴۰۴/۰۸/۱۰ گفت سنجش جمله‌ها با خودش است و QA فقط ثبت تأیید کند. مرحلهٔ بعد PWA است. → `docs/pwa.md` · `docs/product-roadmap.md`

---

## خروجی آن مرحله

- لیست متن‌های اصلاح‌شده (جدول پایین)  
- تأیید ثبت شد ۱۴۰۴/۰۸/۱۰. جمله برای PM: «QA تأیید کرد: متن‌های فارسی»  
- روان بودن جمله‌ها را خود مالک می‌سنجد، نه QA

## تغییرات کلیدی انجام‌شده (قبل / بعد)

| بخش | قبل | بعد |
|-----|-----|-----|
| سایت عمومی — امکانات | امکاناتی که معمولاً در پروفایل باشگاه‌های ایرانی برای تصمیم‌گیری اعضا نمایش داده می‌شود. | همهٔ امکانات لازم برای یک تمرین راحت، تمیز و منظم در یک جا. |
| سایت عمومی — گالری | زون هوازی / سالن وزنه و رک‌ها | بخش هوازی / سالن وزنه و دستگاه‌ها |
| سایت عمومی — تعرفه | هزینه برنامه اختصاصی مربی و پیکرسنجی دوره‌ای جداگانه است. تمدید قبل از انقضا ممکن است تخفیف داشته باشد... | هزینهٔ برنامهٔ مربی و پیکرسنجی جداست. اشتراک خودکار تمدید نمی‌شود؛ اگر قبل از پایان دوره در پذیرش تمدید کنید، تخفیف تمدید زودتر شاملتان می‌شود. |
| ورود و خطای شبکه | ارتباط با سرور برقرار نشد. API را روشن کنید. | ارتباط با سیستم برقرار نشد. چند لحظه بعد دوباره تلاش کنید. |
| ورود اعضا و راهنما | در محیط توسعه از کد ۱۲۳۴۵۶ استفاده کنید / `OTP 123456` | برای تست از کد ۱۲۳۴۵۶ استفاده کنید / کد یک‌بارمصرف: `123456` |
| پنل عضو — سهم هفته | هفته از شنبه تا جمعه است. شمارندهٔ «جلسه در ماه» نداریم — فقط سقف هفتگی. | هفته از شنبه تا جمعه حساب می‌شود و با ثبت خروج، یک روز از سهم هفته کم می‌شود. |
| اعلان سقف هفته (API) | سقف هفته پر شده است. سهم هفته شنبه بعد صفر می‌شود. | سهم تمرین این هفتهٔ شما تمام شده است. از شنبه دوباره می‌توانید وارد شوید. |
| اعلان بدهی روز ۱ تا ۱۴ (API) | ماندهٔ شهریه ... — تا روز ۱۴ ورود باز است؛ از روز ۱۵ تا تسویه بسته می‌شود. | ماندهٔ شهریهٔ شما ... تومان است. تا روز ۱۴ اشتراک ورود باز است، اما از روز ۱۵ تا زمان تسویه بسته می‌شود. |
| اعلان بدهی از روز ۱۵ (API) | ماندهٔ شهریه ... تومان است و فعلاً ورود به‌خاطر بدهی بسته است. | از روز ۱۵ اشتراک گذشته و به‌خاطر ماندهٔ شهریه (... تومان) ورود بسته است. برای تسویه به پذیرش مراجعه کنید. |
| پنل منشی — رد ورود سانس | الان بیرون از ساعت سانس جنس این عضو است | الان ساعت سانس این عضو نیست |
| پنل منشی — لیست امروز | لاگ امروز / بستن خودکار | ورود و خروج‌های امروز / خروج خودکار آخر سانس |
| پنل منشی — ابطال حضور | حضور باطل شد؛ رکورد در لاگ می‌ماند. | این حضور باطل شد (در فهرست امروز با علامت باطل‌شده می‌ماند و سهم هفته برمی‌گردد). |
| پرداخت و تمدید | تخفیف تمدید زودتر ۱۰٪ نمونه / کمتر از نصف برای شروع دوره ثبت نمی‌شود. | با ۱۰٪ تخفیف تمدید زودتر / برای شروع دوره باید حداقل نصف شهریه پرداخت شود. |
| جداسازی متن لاتین (RTL) | برخی کدهای `FS-` و شماره‌ها بدون `ltr-isolate` در لیست پرداخت و مدیریت | همهٔ کدهای `FS-`، ایمیل‌ها، لینک‌ها و شماره‌ها با `dir="ltr"` و `ltr-isolate` |
